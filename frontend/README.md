# ClipMind

Chrome-расширение для пересказа YouTube-видео с помощью нейросети.
Стек: **WXT + React + TypeScript + Tailwind CSS**.

## Возможности

- Берёт ссылку с активной вкладки YouTube и отправляет в API нейросети
- 3 режима пересказа: краткий, умеренный, подробный
- 2 языка пересказа: русский и английский (язык интерфейса всегда русский)
- Светлая и тёмная тема с кнопкой переключения (сохраняется между сессиями)
- Выбор режима, языка и темы сохраняется в chrome.storage.local

> Это фронтенд-часть. Бэкенд (вызов нейросети) подключается через один эндпоинт — см. ниже.

## Установка и запуск (рекомендуемый способ)

```bash
npm install
npm run build
```

После сборки расширение лежит в `.output/chrome-mv3`. Загрузите его в Chrome:

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика» (переключатель справа вверху)
3. Нажмите «Загрузить распакованное расширение»
4. Укажите папку `.output/chrome-mv3`
5. Закрепите иконку ClipMind через значок пазла на панели Chrome

Откройте любое YouTube-видео и нажмите на иконку — появится попап.

> ВАЖНО: используйте `npm run build`, а не `npm run dev`.
> В дев-режиме механизм горячей перезагрузки React в некоторых версиях
> WXT/Vite ломает сборку попапа (ошибка «React is not defined» / пустое окно).
> Продакшен-сборка этого механизма не использует и работает стабильно.
> После каждого изменения кода пересоберите `npm run build` и нажмите
> кнопку обновления (↻) на карточке расширения в chrome://extensions.

## Подключение бэкенда

Вся логика запроса в `lib/api.ts`. Нужно:

1. Заменить `API_BASE_URL` на адрес вашего бэкенда.
2. Эндпоинт `POST /summarize` должен принимать JSON:

```jsonc
{
  "url": "https://www.youtube.com/watch?v=...",
  "mode": "short" | "moderate" | "detailed",
  "language": "ru" | "en",
  "prompt": "..."   // готовая инструкция под режим+язык
}
```

и возвращать:

```jsonc
{
  "summary": "текст пересказа",
  "videoTitle": "название видео"  // опционально
}
```

При необходимости добавьте домен бэкенда в `host_permissions` в `wxt.config.ts`.

## Структура

```
entrypoints/
  background.ts          сервис-воркер (бейдж на иконке)
  popup/
    index.html
    main.tsx             точка входа React
    App.tsx              главный компонент (язык интерфейса фиксирован: UI_LANG = 'ru')
    style.css            Tailwind + CSS-переменные тем
components/
  Logo.tsx               лого ClipMind + глиф YouTube
  ThemeToggle.tsx        кнопка светлая/тёмная
  ModeSelector.tsx       выбор режима пересказа
  LanguageToggle.tsx     выбор языка пересказа
  LoadingBar.tsx         анимация загрузки
  SummaryResult.tsx      экран результата + копирование
  NotYouTubePage.tsx     экран «не YouTube»
hooks/
  useTheme.ts            тема + хранилище
  useSettings.ts         режим/язык пересказа + хранилище
  useYouTubeTab.ts       определение активной вкладки
lib/
  types.ts               типы
  i18n.ts                тексты RU/EN
  api.ts                 запрос к бэкенду + промпты под режимы
```

## Заметки по сборке (уже учтено в конфигах)

- `package.json` содержит `"type": "module"` — иначе Node ругается на ESM-конфиги.
- `wxt.config.ts` форсит `esbuild.jsx = 'automatic'` — иначе в проде «React is not defined».
- `tsconfig.json` дублирует `"jsx": "react-jsx"`.
