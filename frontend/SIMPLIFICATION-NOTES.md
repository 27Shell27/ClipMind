# Что изменилось при упрощении фронтенда

Короткий список правок (для истории и сверки с предыдущей версией).

## Исправлен баг совместимости с бэкендом

Фронт теперь шлёт тело запроса ровно в том виде, что ждёт FastAPI:

```json
{ "youtube_url": "...", "mode": "short|mid|long", "summary_language": "ru|en" }
```

Раньше отправлялось `{ url, mode, language, prompt }` с режимами `moderate`/`detailed` —
бэкенд такие не принимал. Поле `prompt` убрано: промпт строит сам бэкенд.

## Значения режимов приведены к бэкенду

Было: `short` / `moderate` / `detailed`.
Стало: `short` / `mid` / `long` (как в enum бэкенда). Подписи в интерфейсе
остались человеческими: «Краткий», «Умеренный», «Подробный».

## Удалён мёртвый код

- `lib/types.ts`: убраны неиспользуемые типы `SummaryRequest` и `AppState`.
- `lib/api.ts`: убраны `MODE_PROMPTS` и `extractVideoId` (нигде не вызывались).

## Убрана система перевода интерфейса (i18n)

Интерфейс зафиксирован русским, поэтому двухязычная система переводов была
лишней: английские строки никогда не показывались, а функция `t(lang, key)`
всегда вызывалась с `'ru'`. Удалён файл `lib/i18n.ts`, русские строки вписаны
прямо в компоненты. Из сигнатур компонентов убран проп `language`, который
всегда был равен `'ru'`.

Важно: язык ПЕРЕСКАЗА (переключатель ru/en) — это отдельная действующая фича,
она не тронута. Убрана только система перевода подписей интерфейса.

## Мелочи

- `useSettings` теперь проверяет сохранённые значения режима и языка на
  валидность (защита от данных, оставшихся от старой версии).
